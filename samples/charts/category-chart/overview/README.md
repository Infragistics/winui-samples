# Category Chart - Overview

This sample demonstrates the Category Chart component in WinUI 3.

## Running the Sample

Open `WinUIApp.csproj` in Visual Studio 2022 and press F5 to run.

## Requirements

- Visual Studio 2022 (17.8+)
- Windows App SDK 1.5+
- .NET 8

## Description

The Category Chart is a high-performance charting control that automatically
analyzes and selects the best chart type for your data.
