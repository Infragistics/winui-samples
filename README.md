## Explore the samples

- **[Charts](samples/charts):** Reveal trends and relationships with category, financial, radial, polar, scatter, and stacked charts. Explore annotations, highlighting, tooltips, legends, and interactive navigation, alongside pie, multi-ring doughnut, treemap, and sparkline visualizations.
- **[DataGrid](samples/grids):** Help users explore and work with their data through sorting, filtering, grouping, summaries, editing, column customization, and cell merging.
- **[Geographic maps](samples/maps):** Add location context with geographic imagery, shapes, markers, and data-driven geographic series.
- **[Gauges](samples/gauges):** Make key metrics easy to read with radial gauges, linear gauges, and bullet graphs.
- **Dashboard tools:** Bring visualizations and their settings together with [DashboardTile](samples/charts/dashboard-tile) and [Toolbar](samples/charts/toolbar) examples, including property editing for chart configuration.

## Build for Windows with WinUI 3

Turn complex data into clear, interactive experiences in your Windows application. Combine visualizations, editable grids, and contextual dashboard tools using familiar C# and XAML, and explore each component in the combined samples browser or as a standalone sample.
